Excel 100 Hacks & Tricks

လုပ်ငန်းခွင်တွင် အချိန်ကုန်သက်သာစေမည့် လက်တွေ့ Excel လျှို့ဝှက်နည်းလမ်းများ

Hack #01: Dynamic Lookup

XLOOKUP vs VLOOKUP: ဘာကြောင့် XLOOKUP သုံးသင့်လဲ?

Column အညွှန်းနံပါတ်တွေ ရေတွက်စရာမလိုဘဲ ဘယ်ဘက်ခြမ်းကိုပါ တိုက်ရိုက် Lookup ရှာဖွေနိုင်သော ခေတ်မီ နည်းစနစ်။

=XLOOKUP(lookup_val, lookup_arr, return_arr, "Not Found")
Hack #02: Text Extraction

TEXTBEFORE & TEXTAFTER ဖြင့် စာလုံးခွဲထုတ်ခြင်း

LEFT, RIGHT, MID, FIND တွေကို ရှုပ်ထွေးစွာ ပေါင်းစပ်စရာမလိုဘဲ ကန့်လန့်ဖြတ် စာသားများကို စက္ကန့်ပိုင်းအတွင်း ခွဲယူနည်း။

=TEXTBEFORE(A2, "@") & =TEXTAFTER(A2, "@")
Hack #03: Data Cleaning

Merged Cells များကြား Null Values ဖြည့်နည်း

F5 (Go to Special > Blanks) ဖြင့် အပေါ်က အကွက်တန်ဖိုးကို အောက်ကွက်လပ်များအားလုံးသို့ Ctrl + Enter ဖြင့် တစ်ပြိုင်နက် Auto ဖြည့်နည်း။

=A2 (Press Ctrl + Enter for All Blanks)
Hack #04: Dynamic Array

FILTER Formula ဖြင့် အစီရင်ခံစာ Auto ထုတ်ခြင်း

အခြေအနေတစ်ခု သို့မဟုတ် အများအပြားနှင့် ကိုက်ညီသော စာရင်းများကို သီးခြား Table တစ်ခုအဖြစ် Auto Spill ခွဲထုတ်ပေးသော ဖော်မြူလာ။

=FILTER(DataRange, Department="Finance", "No Records")
Hack #05: Multi-Condition

SUMPRODUCT ဖြင့် ရှုပ်ထွေးသော KPI များ တွက်ချက်ခြင်း

Boolean Logic (--) ကို အသုံးပြု၍ Condition အစုံကို Array Multiplication ဖြင့် အမြန်ဆုံး တွက်ချက်နိုင်သော အစွမ်းထက် ဖော်မြူလာ။

=SUMPRODUCT((Branch="YGN")*(Target>500)*(Actual))
Hack #06: Power Query Tip

Folder Import: ဖိုင် ၁၀၀ ကို ၁ စက္ကန့်အတွင်း ပေါင်းနည်း

နေ့စဉ် လစဉ် ရောက်လာသော Excel ဖိုင်များကို Copy-Paste လုပ်စရာမလိုဘဲ Folder လမ်းကြောင်း ချိတ်၍ One-Click Refresh ပေါင်းစပ်နည်း။

Data > Get Data > From File > From Folder
