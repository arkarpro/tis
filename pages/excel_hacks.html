Hack #01: 1-Click Folder Automation with Power Query

Power QueryAutomation
ဆွေးနွေးရန် / အပ်နှံရန် ➔

ရုံးခွဲပေါင်းများစွာမှ ပို့လာသော Excel ဖိုင် ရာနှင့်ချီကို Copy-Paste လုပ်စရာမလိုဘဲ 1-Click ဖြင့် အလိုအလျောက် ပေါင်းစပ်နည်း။

Power Query ၏ Folder Connector ကို အသုံးပြု၍ လစဉ် ရုံးခွဲဖိုင်များကို Auto-Combine ပြုလုပ်ပြီး Error များကို သန့်စင်သည့် အဆင့်များကို Script အဖြစ် အလိုအလျောက် Run စေခြင်း ဖြစ်ပါသည်။ ဖိုင်အသစ် ရောက်လာတိုင်း Refresh တစ်ချက်နှိပ်ရုံဖြင့် အားလုံး ပြီးမြောက်ပါသည်။

Hack #02: Dynamic Two-Way Lookup with XLOOKUP

Excel FormulaXLOOKUP
ဆွေးနွေးရန် / အပ်နှံရန် ➔

VLOOKUP ထက် အဆပေါင်းများစွာ ပိုမိုစွမ်းဆောင်နိုင်သော Two-Way Matrix Lookup နည်းပညာ။

XLOOKUP function နှစ်ခုကို ဆင့်ကဲ (Nested) အသုံးပြုခြင်းဖြင့် Row နှင့် Column နှစ်ဖက်စလုံးမှ တန်ဖိုးများကို တိကျစွာ ဆွဲယူနိုင်ပြီး Formula ကျိုးပေါက်ခြင်းမှ ကာကွယ်ပေးနိုင်ပါသည်။
