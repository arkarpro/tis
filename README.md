## Package Contents:
1. `pages/` (10 Full HTML Files):
   - `about.html` (Tab: HOME_About)
   - `projects.html` (Tab: HOME_Projects)
   - `free-hacks.html` (Tab: FREE_Excel_Hacks)
   - `free-videos.html` (Tab: FREE_Videos)
   - `free-articles.html` (Tab: FREE_Articles)
   - `course-excel.html` (Tab: COURSE_Excel)
   - `course-pq.html` (Tab: COURSE_PowerQuery)
   - `course-pbi.html` (Tab: COURSE_PowerBI)
   - `course-sql.html` (Tab: COURSE_SQL)
   - `reviews.html` (Tab: TEST_Reviews)

2. `js/api.js`:
   - Configured with your Web App URL.
   - Auto-resolves images from `Media_Files/<folder>/<image_name>`.
   - Formats links and buttons automatically.

3. `gas/Code.gs`:
   - Full Google Apps Script API engine.

## Installation in your local `tis` folder:
1. Unzip `tis_cms_package_v5.2.zip`.
2. Copy `pages/` into `tis/pages/` (it now contains all 10 HTML files).
3. Copy `js/api.js` into `tis/js/api.js`.
4. Open any page in browser or push to GitHub Pages!
